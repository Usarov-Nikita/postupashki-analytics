# Источники данных для seed.py

CSV восстановлены из поставляемой mvp.sqlite. Исторические заказы, маркетинговая хронология, прогноз и причинный пример выгружены без изменения значений. Демонстрационные заказы ограничены исходными ЗАК001–ЗАК013; переходы — исходными записями демо_переход_*. Шесть покупок, добавленных при ручной демонстрации, не включены в начальный набор.

Это восстановленный набор для автономной сборки, а не оригинальные файлы промежуточных этапов анализа. Демонстрационные данные синтетические; прогноз сохранён из исходного артефакта и не пересчитывается относительно даты запуска.
